## Fix status after the same-day pass

| Row | Status | What changed |
|---|---|---|
| CRITICAL `VpnApi.kt:92` | **fixed** | `OnboardingRepository.signInAndProvision` wraps the pipeline in `withContext(Dispatchers.IO)`; `OnboardingTest.runsTheNetworkCallsOffTheCallersThread` guards it, mutation-checked against `Dispatchers.Unconfined`. |
| HIGH `Onboarding.kt` cancellation | **fixed** | `catch (e: CancellationException) { throw e }` before the generic catch; the tunnel's own `connect` does the same and tears the tunnel down under `NonCancellable`. |
| HIGH `SecretStores.kt` keystore on main | **fixed** | Both stores build `EncryptedSharedPreferences` lazily with the application context; key reads in `TunnelController.connect` dispatch to IO. |
| HIGH `WireguardTunnelEngine` per-Activity backend | **fixed** | `VpnGraph` in `MainActivity.kt` is one graph per process (`@Volatile` + double-checked init), so a rotation no longer builds a second `GoBackend`, abandons an `OkHttpClient`, or resets tunnel state to `Down`. Residual: the engine has no `close()`, which is acceptable for a process-scoped object but means the backend's thread lives until process death. |
| HIGH `AllowedIPs` / own traffic in tunnel | **fixed** | `tunnel/TunnelSockets.kt` adds `ProtectingSocketFactory`, wired into `VpnApi.defaultClient(...)` from `VpnGraph`: every outbound socket is passed to `VpnService.protect()` *before* `connect()`. `ProtectingSocketFactoryTest` pins the ordering (`protect` must see an unconnected socket) and that a missing exemption degrades to "connected anyway" rather than a failed sign-in. |
| MEDIUM `PrefsSessionStore` eager+unguarded | **fixed** | Lazy, and both stores are now nullable with null-safe accessors, so a reset/re-keyed keystore degrades to "nothing stored" and the idempotent pipeline re-provisions instead of crashing every launch. |
| MEDIUM token never rehydrated/rotated | **fixed** | `VpnApi` takes `loadToken`/`saveToken`, hydrates on first use, persists every rotation, and rotates once + retries once on `401` (with `rotateOn401 = false` on the rotate call itself, so it cannot recurse). `OnboardingController.signOut()` clears key + ids + token off the main thread, and `VpnScreen` exposes a header "Sign out" button, covered by two new instrumented tests. |
| MEDIUM `connect` races `startForegroundService` | **fixed** | `awaitService()` polls `WgTunnelService.instance` for up to 2 s with 25 ms steps before reporting failure. |
| MEDIUM key in many `String`s | **partly fixed** | `GeneratedKeyPair.toString()` redacts the private key (`GeneratedKeyPairTest`), and the unused `FakeTunnelEngine` - which existed only to retain the private key - is deleted. The immutable-`String` copies the library API forces are still there. |
| MEDIUM recomposition in `VpnScreen`/`MainActivity` | **fixed** | `planLabel`/`endpointLabel`/`addressesLabel` and the sign-out callback are `remember`ed against their inputs in `MainActivity`, and `PasswordVisualTransformation()` is `remember`ed in `SignInFields`. Still unmeasured on a device — no emulator on this host. |
| LOW `OkHttpClient` per Activity | **fixed** | Same `VpnGraph` change: one client for the process. |
